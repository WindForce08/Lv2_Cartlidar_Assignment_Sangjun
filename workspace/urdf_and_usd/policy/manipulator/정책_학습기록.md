## 3. 주사위 2 만들기: 집기 P2 + 놓기 P1 (A 방식 = 정책 2개 이어 쓰기)

시작: 2026-10-28. 미션 (mission.pdf, 주사위 기억 로봇) 의 '주사위 눈 배치' (장소당 10 점) 를 로봇 제자리에서 먼저 연습하는 과제.

### 3.1 과제 정의

- 로봇은 움직이지 않음 (바퀴 속도 0). 팔만 씀.
- A 상자 (205 x 205 x 70 mm, 미션 시작 상자) 위에 퍽 2 개 (상자 중심에서 지도 X ±40 mm), 그중 A 퍽 1 개를 집음.
- B 상자 (205 x 205 x 70 mm) 위에 B 퍽 1 개가 주사위 2 의 한 칸에 있음. A 퍽을 다른 칸에 놓아 **주사위 2** 완성.
  - 주사위 2 = 3 x 3 격자 (간격 60 mm, 격자 중심 = 상자 중심) 의 왼쪽 위 (−60, +60) 와 오른쪽 아래 (+60, −60), 지도 +Y 가 위, 돌려서 대체 불가. 두 퍽 거리 약 170 mm.
- 성공 (미션 채점 기준): 각 칸 중심 오차 ≤ 10 mm, 퍽 바닥 = 상자 윗면 (70 mm), 똑바로 서서 2 s 안정, 다른 칸 비어 있음. 정책 목표는 시뮬레이션에서 ≤ 5 mm.
- 퍽: 3 x 3 x 6 cm 원기둥 (지름 30) · 직육면체, 빨강·초록 (질량 45 / 55 g 추정).

### 3.2 방식 (A: 정책 2 개)

| 정책 | 시작 상태 | 끝 (성공) |
|---|---|---|
| P2 집기 `Waffle-Pick-Direct` | 팔 준비 자세, 집게 열림, A 상자 위 퍽 2 개 | A 퍽을 3 cm 이상 들고 유지, 옆 퍽 그대로 |
| P1 놓기 `Waffle-Place-Direct` | A 퍽을 쥐고 든 상태 (학습 때는 바로 이 상태로 시작) | 목표 칸 오차 ≤ 5 mm, 똑바로, 놓고 집게가 빠진 뒤 2 s 유지, B 퍽 그대로 |

이어 쓰기: P2 성공 판정 → P1 시작. 평가 = 두 정책을 이어 '주사위 2 완성률' 과 오차 분포.

### 4.11 매니퓰레이터 모델 구성 · ROS 연결 규칙 (2026-10-29 결정)

단계마다 모델 (정책 파일) 을 따로 만들고, ROS 노드 하나가 모두 불러 상태 머신으로 골라 씀 (합치기 = 실행할 때 이어 붙이기. 모델 하나로 증류는 전체가 다 된 뒤 필요하면).
'에피소드' 는 학습 때 시도 1 번 (리셋 -> 끝) 일 뿐, 결과물은 모델 파일 (가중치) 하나. 실제 로봇은 에피소드 없이 30 Hz 로 계속 관측 -> 행동.

- 강화 학습이 꼭 필요한 곳 = 매번 위치가 바뀌는 단계 (1 인식 좌표, 5 상자·칸 위치). 스토리지는 몸체에 고정이라 4 (와 깔때기가 생기면 2·3) 은 고정 궤적으로 될 수 있음.
- 통 입구에 깔때기가 생기면 2 와 3 을 합칠 수 있음 (모델 4 개).

**ROS 연결 규칙 (manipulator 노드, 30 Hz)**
1. 관측은 학습 때와 똑같이: 순서, 좌표계 (base_link), 단위 (m, rad), 기준 자세 (관측 = 관절 − 과제의 기준 자세). 관측 정규화는 내보낸 모델 (`exported/policy.pt`·`policy.onnx`) 안에 있음.
2. 행동 해석도 같게: 1·2 = 팔 관절 목표 += 0.04 rad x 행동, 실제 각 ±0.25 rad 안, 관절 한계 안. 3 = 집게 끝 (잡는 점) 위치 변화 (아래 4.12) -> IK. 집게 = 행동 > 0 이면 벌림 0.015, 아니면 닫기 −0.0014 (gripper_left_joint).
3. **실제 로봇에서 못 재는 값은 관측에 넣지 않음**: 퍽 자세 (시뮬레이션 참값) 는 2 (ST3) 가 아직 씀 -> 나중에 빼고 다시 학습. 3 부터는 실제로 얻을 수 있는 것만 (관절 위치·속도·토크 (= 다이나믹셀 전류), 정기구학 잡는 점, 통 위치 (고정), 손가락).
4. 단계 전환 조건은 위 표 (정기구학 + 인식 + 집게 값으로 판단).

- 실패한 회차도 지우지 않고 남김: **무엇을 바꿨는지 · 숫자 결과 · 원인 (확인한 방법)** 을 같이.
- 결과는 학습 중 지표 (보상·에피소드 길이·Metrics/*) 와 평가 결과를 구분해서 적음.

## 부록 B. 이전 로봇 (TeamRobot, 2026-10-26 퍽 잡기) 에서 배운 보상 설계 교훈

로봇이 달라 설정값은 그대로 쓰지 않지만, 잡기 같은 정책을 만들 때 다시 확인할 원칙입니다.
- 실패하면 **종료 + 큰 벌점** 을 주면 정책이 아예 아무것도 안 하는 해로 감 → 실패 상태는 스텝 벌점으로.
- 단계 사이가 멀면 (접근 → 들기) **중간 디딤돌 보상** ('잡음': 손가락이 물체에 막혀 멈춤) 이 필요. 단, 꼼수로 채울 수 없게 조건을 건다 (차체가 기울면 안 줌 등).
- 위치 제어 **목표각이 실제보다 크게 앞서면** 큰 힘이 나와 바닥을 짓누르는 꼼수가 생김 → 앞섬 제한 (±0.25 rad) + 차체 기울기 벌점.
- 다음 단계 보상은 **계단식 (3 cm 넘어야) 이 아니라 연속형 (1 mm 부터)** 으로. 계단식이면 잡기까지 배운 정책도 들기를 못 찾음.
- 막히면 정책이 한 단계를 해 놓은 상태에서 **스크립트로 다음 단계를 해 보는 진단** 으로 물리 문제인지 탐색 문제인지 가른다.
- 학습 전에 **손으로 푼 IK 스크립트로 같은 동작이 물리적으로 되는지** 먼저 확인.
