## 충돌 형상

- **가벼운 판** (`collision:=light`, Isaac light · loaded): 브라켓 · 블록 · 받침 · 모터 · 덮개 · 받침판은 상자, 팔레트는 바닥판 외곽 상자 (두께 3) + 칸마다 칸 방향으로 돌린 상자 (칸 바깥 외곽, 칸 속 · 손가락 홈 무시). **집기 시험은 정밀 판으로.**

## 확인할 것 ★

1. **stow (전원 켤 때 자세) 로 가는 길에 팔이 팔레트에 걸림.**
   - 최종 stow 자세는 닿지 않지만 가깝다: 위팔 (link3) ↔ 팔레트 4.0 mm (볼록 메시) · 0.9 mm (상자), ↔ 퍽 10.7 mm.
   - 조인트1 이 90° 까지 돌기 전에 J2 · J3 · J4 가 다 접히면 위팔이 팔레트 칸에 최대 25 mm 파고든다 (J1 0 ~ 1.4 rad). Isaac 점검은 모든 관절을 같이 움직여 J1 약 81° 에서 걸려 멈춘다.
   - **zero → stow 는 J1 을 먼저 다 돌린 뒤 접을 것**, 또는 stow 자세를 바꿀 것. 주행 자세 (drive) 는 팔레트 · 퍽과 닿지 않음 (팔 ↔ 퍽 21.7 mm).
2. **팔레트 체결 구멍.** 팔레트는 조인트1 x 92.8 (상판 앞에서 40 mm) 기준으로 설계됐고, 이 모델은 팀 조인트1 x 96.0 에 맞췄다. 실물 상판 구멍에 그대로 놓으면 칸 원호 중심이 조인트1 보다 3.2 mm 앞. 실물 조인트1 위치를 재서 확인.
3. **팔 · 집기 자세.** 설계 `pallet_slots.yaml` 의 관절값은 OM-X 팔 기준. 팀 팔 (RM-X52 + 롤 손목) 로 12칸 집기 · 퍽 든 채 회전 (상판 + 145 mm) 을 다시 확인. 팀 J1 한계 ±180°, 팔레트 설계의 금지 구간 247 ~ 293° (팔 0° = 왼쪽 기준).
4. **회전 중심 12.5 mm.** 브라켓 · 벨트 · 바퀴 · 캐리어가 판보다 x +12.5 mm 앞 (사용자 결정 2026-11-01: 설계 그대로). 제자리 회전 때 `base_link` 가 반지름 12.5 mm 원을 그림 → Nav2 · diff_drive 가 base_link 를 회전 중심으로 보면 약간 어긋남. 실물 바퀴 축 x 를 재서 확인.
5. **LiDAR 가림.** LDS-03 스캔면 (지면 위 82.2 mm) 이 위층 OpenCR (z 59.7~96.4) 을 지남. 차체 가림 앞 139.5° → 179.1°, 뒤 195.3° → 220.5°.
6. **IMU 하나.** 시뮬은 `/imu/data` 를 바로 냄 (frame `imu_link`). 팀의 두 IMU 평균 노드는 시뮬에서 쓰지 말 것. `config/sensors.yaml` 의 `imu` 도 하나 (`opencr_lower_link` → `imu_link`) 로 고침 (2026-11-02).
7. **어림값.** Jetson 포트 방향 (설계 상자에 맞춰 메시를 90° 돌림), 배터리 자리, 지지대 · 아이들러 질량.
8. 바퀴 속도 · 감쇠 등 물리값은 261028 `robot_params.json` 그대로 (벨트 1 : 1.5).
