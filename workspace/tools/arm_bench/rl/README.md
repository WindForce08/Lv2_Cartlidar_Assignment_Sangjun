# arm_bench/rl: 팔 집기·놓기 강화학습 (Isaac Lab 3.0)

받침대 (테이블) 에 고정한 팔 (RM-X52 + 손목 롤 + 집게) 로 테이블 위 퍽 (원기둥 Ø30 × 60 mm) 을 **옆에서 (집게 수평)** 집어 목표 자리에 세워 놓는 과제 `ArmBench-PickPlace`.
차체 URDF (팀원 2안) 가 오기 전, 팔만으로 할 수 있는 학습입니다. 이미 설치된 Isaac Sim 6.1 / Isaac Lab 3.0 (`~/pa-course/IsaacLab-6.1/.venv`) 을 그대로 씁니다 — 새로 설치하지 않음, 창 없이 (play 만 창).

## 명령

```bash
cd ~/GIT/Lv2_Cartlidar_Assignment/workspace/tools/arm_bench/rl
./run.sh convert                 # ../urdf/arm_bench.urdf -> usd/arm_bench_sim/ (URDF 를 바꿨을 때만)
./run.sh check                   # 물리 확인: IK 로 짠 순서로 퍽 집어 옮기기 (학습 전에 풀 수 있는 문제인지) -> results/check_pick.json
./run.sh train [환경 수] [반복]   # 기본 256 환경 · 1500 반복 (약 21 분) -> logs/rsl_rl/arm_pick/<시각>/
./run.sh eval [--episodes 500]   # 성공률 -> results/eval.json, 정책 파일 -> 그 학습 폴더 exported/policy.pt · policy.onnx
./run.sh play [환경 수]           # 창으로 재생 (화면 필요, 목표 자리 = 초록 원판)
./run.sh board                   # 학습 곡선 http://localhost:6006
```

## 실물과 맞춘 것 (한 곳에서 읽음)

| 항목 | 값 | 어디서 |
|---|---|---|

| 팔 강성 | P 800 → 18.9 N·m/rad, 감쇠 0.85 (역기전력) | `config.h` ARM_POS_P_GAIN 을 `robot_cfg.py` 가 환산. **I 게인은 시뮬에 없음** (튜닝으로 I > 0 이면 실물이 덜 처짐) |
| 손가락 | 닫힘 −11 · 열림 +20 mm (실측 2650 · 1550 tick), 미는 힘 13 N/손가락 | 펌웨어 쥐는 힘 `GRIP_SQUEEZE_TICKS` 33 → 모터 0.96 N·m × 효율 0.5 ★ |

## 과제 (`arm_pick/pick_env_cfg.py`)

- 행동 4개: 집게 끝 이동 dx · dy · dz (× 6 mm/주기, 30 Hz) · 쥐기 (> 0 닫기). 집게 끝 목표 → IK (`arm_pick/kinematics.py`, 수평 집게) → 관절 목표.
  실물에서도 같은 IK 로 관절 목표 → 펌웨어 팔 칸 0~4, 쥐기 → 6 번째 칸 2650 (닫힘) / 1550 (열림) tick. 막히면 펌웨어 GripGuard 가 약하게 쥠.
- 관측 25개: 집게 끝 · 손가락 · 퍽 · 퍽−끝 · 퍽 세움 · 목표 · 목표−퍽 · 팔 관절 5 · 이전 행동 · 들었었음.
  실물에서 퍽 · 목표 위치는 카메라나 사람이 줘야 함 (아직 없음).
- 보상: 다가가기 → 쥐기 → 들기 (1.5 cm) → 목표 위로 → 내려놓기 → 놓고 빠지기 (성공, 끝). 넘어뜨림 · 30 cm 밖으로 밀림 = 실패 (끝).
- 퍽 · 목표: J1 축에서 25 ~ 33 cm, ±40°, 서로 6 cm 이상. 시작 집게 끝 (0.232, 0, 0.11) - 퍽보다 안쪽 · 위.

### 왜 수평 잡기인가 (계산 · 시험으로 확인)

- 위에서 내려 잡기는 안 됨: J4 상한 2.0 rad (모터 EEPROM 3352 tick) 때문에 집게가 아래를 볼 때 손가락 끝이 최고 약 5 cm → 60 mm 퍽 위를 못 지나감.
- 손가락 실제 끝 (충돌 상자) 은 URDF end_effector_link 보다 21 mm 더 나감. 패드는 gripper_link x 0.12 ~ 0.16 (40 mm).
- 수평 잡기는 퍽이 J1 축에서 24 cm 넘게 떨어져야 테이블 높이 (집게 끝 4.5 cm) 에 닿음 — 가까우면 팔을 그만큼 못 접음 (J4 −1.92 한계).
  24 ~ 36 cm · 높이 4.5 ~ 12 cm 에서는 모든 관절이 한계에서 10° 넘게 여유.
